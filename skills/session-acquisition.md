# 测试用登录态获取

> 登录态是**测试前置条件**，不是漏洞。
> 拿不到登录态时，正确做法是**明确声明并评估替代面**，而不是硬造账号或撞库。

## 一、什么时候用

- 资产测绘发现核心功能（订单/资料/后台/导出）全在登录后
- 接口返回 401，但前端页面能正常浏览
- 已有浏览器登录，但需要用 curl/脚本复现

## 二、先识别鉴权形态（决定后面怎么复用）

| 形态 | 特征 | 复用方式 |
|---|---|---|
| **Cookie 会话** | 请求带 `Cookie: SESSION=...`，值不可读 | 直接带 Cookie 头 |
| **Bearer JWT** | `Authorization: Bearer eyJ...` | 解 JWT payload 看 `uid`/`role`/`exp`，带同一头 |
| **自定义头** | `token:`、`X-Token:`、`Access-Token:` | 逐个试头名（常见坑：不是 `token` 而是 `Authorization`） |
| **签名型** | 改参数报「ts 有问题」→「nonce」→「mac」 | 需逆向签名算法（见下） |
| **双 Token** | access + refresh，短时效 | 记录刷新逻辑，复现时先刷新 |

**实用判断法**：登录后 F12 看**任意一个业务请求**的头——鉴权头就在那里。

## 三、合法获取途径（按优先级）

| # | 途径 | 说明 |
|---|---|---|
| 1 | **客户提供测试账号** | 最干净；要写明权限级别 |
| 2 | **自注册**（**先问用户**） | 只注册 1 个，不批量；注册链路走不通就停，不要反复试验证码 |
| 3 | **测试环境/预发环境** | 常有弱口令或开放注册 |
| 4 | **API Token 申请** | 开放平台常可自助申请（需审核则记录审核周期） |
| 5 | **SSO 单点登录复用** | 一套账号打通多个子系统 → 一个号拿到多个面 |

**明确不做**：撞库、爆破、购买账号、借用他人账号、批量注册。

## 四、拿到后怎么迁移到 CLI

### Cookie
```bash
curl -s "https://target/api/user" -H 'Cookie: SESSION=xxxx'
```

### Bearer JWT
```bash
TOK='eyJ...'
curl -s "https://target/api/user" -H "Authorization: Bearer $TOK"
# 先看 payload（不校验签名也能读）
echo "$TOK" | cut -d. -f2 | base64 -d 2>/dev/null
```

### 头名不确定时（**常见坑**）
```bash
for h in token Authorization X-Token Access-Token Store-Token; do
  code=$(curl -s -o /dev/null -w "%{http_code}" "https://target/api/user" -H "$h: $TOK")
  echo "$h -> $code"
done
```

### 签名型（ts/nonce/mac）
1. 反编译客户端 / F12 全局搜 `sign`、`mac`、`signature`
2. 找到拼接规则（常见：`md5(ts + nonce + secret + body)`）
3. 本地复算，与原签名比对一致即成功

## 五、判定标准

| 检查 | 通过标准 |
|---|---|
| 能调通需要鉴权的接口 | 返回业务数据（不是 401） |
| 令牌未过期 | payload 的 `exp` 在未来 |
| 权限级别已知 | 能说清是普通用户/管理员 |

## 六、证据要求

- 鉴权形态判定依据（请求头截图/原始报文）
- 登录成功的一次响应（脱敏）
- 若为自注册：注册时间 + 账号用途说明（**不写明文口令进报告**）

## 七、失败判据（拿不到时怎么办）

| 情形 | 处理 |
|---|---|
| 注册要短信且收不到 | 停，记录"无法自助注册"，**不要反复试** |
| 注册需人工审核/OA 审批 | 记录审核链路，向用户申请账号 |
| 只有内部员工才能登录 | 声明该面不可测，转未登录面 |
| 需要实名/KYC | 声明不可测（涉及个人信息，不代填） |

**拿不到登录态时必须做的事**：在阶段 2 结束时明确告知用户"这些面不可测"，并列出可替代的未登录面，而不是等出报告才说 0 条。

## 八、边界

- 自建账号**只用于验证越权**（"普通用户能读到他人数据"是有效证据），**账号本身不计权限得分**
- 不修改账号资料、不做写操作
- 不把登录态写入任何公开文件；本地临时文件用完删除
- 发现他人令牌（日志/前端泄露）时：只证明其可用性，**不长期持有**
