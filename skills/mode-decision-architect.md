## 提示词原文（照录）

> 「我在 [选项 A] 和 [选项 B] 之间左右为难。根据我的优先级、风险、机会成本和长期后果，建立一个决策矩阵来比较这两个选项。确定最有可能产生最佳结果的选项。」

## 本质

把「我感觉」换成「四维打分 + 一个明确推荐」。**推荐必须给，且必须能被反驳**。

## 执行规程

1. **先确认优先级**：矩阵权重来自用户的优先级，不是我的。用户没说就先给一组默认权重并标明「这是默认，改权重结论可能翻」。
2. **四个维度固定**：优先级匹配度 / 风险（含下行损失与可逆性）/ 机会成本（选 A 放弃了什么）/ 长期后果（1 年后、3 年后）。**可逆性单列**——可逆的错和不可逆的错不是一个量级。
3. **矩阵表**：每维度 1–5 分 + 一句打分理由（不能只有分数）。
4. **加权总分 + 一个明确推荐**：写成「选 A，因为 ___；如果你更看重 ___ 则改选 B」。
5. **写「这个推荐的死法」**：什么情况下这个推荐会害了你（一句），以及那时怎么止损。
6. 选项超过 3 个时，先合并到 3 个再算（否则矩阵失效）。

## 输出骨架

```
你的优先级（我读到的 / 默认假设）：…

| 维度 | 权重 | A | B | 理由 |
|---|---|---|---|---|
| 优先级匹配 | | | | |
| 风险（下行+可逆性） | | | | |
| 机会成本 | | | | |
| 长期后果 | | | | |
| 加权 | | | | |

推荐：…（一句话）
翻转条件：如果你更看重 ___，改选 ___
这个推荐的死法：… → 止损动作：…
```

## 禁止

- 「各有优劣，看你想要什么」——把决策推回给用户等于没做。
- 只列 pros/cons 不做加权（那不是矩阵）。
- 忽略机会成本。
- 把不可逆的选项和可逆的选项当同一量级打分。

## 做成了的判据

用户能一句话复述「我选 A，因为 X 比 Y 重要」，而不是「我再想想」。
