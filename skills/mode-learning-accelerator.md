## 提示词原文（照录）

> 「我想尽可能高效地掌握 [技能]。为我建立一个基于刻意练习、主动回忆、间隔重复和动手项目的学习系统。专注于提供最大实际优势的知识。」

## 本质

不是课程表，是**四机制合一的操作系统**：刻意练习（练最弱的那个子技能）+ 主动回忆（合上书能说出来）+ 间隔重复（定时打击遗忘）+ 动手项目（用真实任务逼出能力）。

## 执行规程

1. **拆技能**：把 `[技能]` 拆成 4–6 个子技能，标出「**80% 的实战价值在哪 2 个**」。只精修这 2 个，其余过关即可。
2. **定验收**：给一个「能证明我会了」的最小作品（可交付、可给别人看、有明确合格线）。
3. **四机制落成动作**（每条具体到动作与频率）：
   - 刻意练习：练哪个子技能、怎么练、每次多长、错在哪算练到（练习必须让错误率可观测）
   - 主动回忆：每天 5 分钟「空手复述」复述什么，写在哪里
   - 间隔重复：间隔表（1/3/7/21 天）打什么卡，什么内容不该进卡（理解型不必背）
   - 项目：2–3 个递增的真实项目，第一个必须一周内能交付
4. **给 4 周时序**：每周目标 + 产出物 + 自检点。
5. **反模式**：写「这个技能上最容易浪费时间的三件事」（看教程代替动手、收藏资料、学用不上的分支）。
6. 声明「最大实际优势」的边界：哪些知识这个阶段**故意不学**。

## 输出骨架

```
技能拆解：…｜80% 价值在：子技能 A、B（其余过关即可）
最小合格作品：…（合格线：…）

机制
刻意练习：…（错误率判据：…）
主动回忆：…（每天 5 分钟复述：…）
间隔重复：1/3/7/21 天，卡片内容：…（不进卡的：…）
动手项目：P1 …（一周交付）→ P2 … → P3 …

四周时序：W1 … ｜ W2 … ｜ W3 … ｜ W4 …
刻意不学：…
最浪费时间的三件事：…
```

## 禁止

- 给一份「从入门到精通」的资源清单。
- 四机制只留名字不落到动作。
- 时间承诺写「大约几个月」（无判据）。
- 让人先系统学完基础再动手（顺序反了）。

## 做成了的判据

用户当天就有第一个 30 分钟的练习可做，且知道练错的表现是什么。
