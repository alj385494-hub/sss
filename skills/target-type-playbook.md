# 靶标类型打法库（Target-Type Playbook）

> **用途**：拿到一个新靶标，先判断它属于哪一类，直接查对应打法 —— 不用每次从零想。
> **来源**：2026-11-10 ~ 11-12 实测 9 个真实靶标后提炼，每条都标了实证来源。
> **分工**：本文件只管「怎么打」（能力层）；「交不交」与平台规则属交付层技能，不在本文件。

---

## 一、开工 30 秒：判断类型

```
看官网首页 → 判断它靠什么赚钱 → 对号入座下面 8 类
```

| 快速识别信号 | 归类 |
|---|---|
| 教务/选课/图书馆/一卡通/招生，域名 .edu.cn 或学校名 | **A 高校/教育** |
| 论坛/贴吧/同城/分类信息，bbs 子域 | **B 地方社区/论坛** |
| 「开放平台/SaaS/解决方案/多客户」，客户子域成片 | **C 多租户 SaaS** |
| 数据超市/接口市场/API 计费/会员调用 | **D 数据交易平台** |
| 司法/裁判文书/涉诉/开放 API + 文档中心 | **E 司法/政务数据开放平台** |
| 医院名/挂号/预约/报告查询 | **F 医疗** |
| 「软件定制开发/外包/网站建设/案例展示」 | **G 软件外包/定制开发** |
| 「AI 解决方案/数字化/AI 中台」，Next.js 站 | **H AI/数字化解决方案商** |
| 机器人/人形机器人/具身智能/SDK 与固件下载 | **I 机器人/具身智能** |
| 本地生活/社区 App 底座，客户站有 `app*.cloud.xxx` | **C 多租户 SaaS**（优先） |

## 二、八类打法

### A · 高校 / 教育

| 项 | 内容 |
|---|---|
| **典型资产面** | 教务/选课、图书馆、OA、邮箱、Azure AD/M365、VPN、招聘、继续教育、学报 |
| **优先攻击面（2026-11-13 修订，按命中率重排）** | ①★**下拉/模糊搜索类接口的响应过度**（选老师/选班级/选课程 → 前端只显示姓名，后端可能返回学号+身份证+手机+学院；见「接口挖掘手法」M7）<br>②**JS 里挖隐藏接口**（F12 全局搜 `api/`、`stu`、`jwc`、`lib` 等碎片，见 M1）<br>③教务/图书馆的未授权查询接口（含 PII 才算数，纯配置页会被驳）<br>④老 OA / 统一身份认证（泛微、正方、强智、金智）→ 先查「不关注名单」<br>⑤VPN 与堡垒机边界<br>⑥Azure AD / M365 账号枚举（**多数平台把「用户名枚举」视为低价值**，故优先级下调；平台是否收录以平台层规则为准） |
| **P1 数据面** | 学生/教师名录、成绩、招生报名、招聘简历（含姓名+身份证+手机） |
| **常见坑** | 教材站常是 SPA，命令行抓不到内容；注册要短信验证码，**经常发不出去**（无法自助拿账号） |
| **实证** | 江西师大（<客户域名>）：4 条候选，1 条被驳（选课配置页——纯配置泄露+理论影响）；Domino 那条自查为误报。<br>北京中教互联（jiaoyu.cn）：0 条，SPA + ZS-Proxy WAF + 注册无法收验证码。<br>某高校（csu.edu.cn，2026-11-13）：**920 子域 → 493 解析 → 339 存活站**，nuclei 130 URL 零命中、端口扫 170 IP×15 仅 4 开放、接口全 401/302 → **0 条**。<br>**教训**：339 站只做通用扫描 = 高质量的空；缺的正是「JS 挖接口(M1)」+「下拉框响应过度(M7)」 |
| **最可能出成果** | **账号枚举类**（不需要登录）> 未授权接口 > 老 OA Nday |

### B · 地方社区 / 论坛

| 项 | 内容 |
|---|---|
| **典型资产面** | 论坛主站（Discuz/PHPWind）、App API、垂直频道（房产/婚嫁/招聘/汽车）、图床、广告投放 |
| **优先攻击面** | ①**越权/IDOR**（帖子、私信、资料、订单，**需登录态**）②App API 未授权 ③上传点（头像/图片/附件）④广告平台 CORS/越权 |
| **P1 数据面** | 用户手机号、实名信息、地址、交易记录（社区类通常量大） |
| **常见坑** | 主站常被 WAF 全站拦（阿里云 410 + 10.9KB / acw_sc__v2 JS 挑战）；论坛系统常已加固参数化；**子域挂博彩/黑页多为域名滥用（事件型），不是漏洞** |
| **实证** | 某本地生活平台（<客户域名>）：0 条。PHPWind 8.3 已 addslashes+强转；WAF 全站 410；越权全在登录态，注册需验证码 |
| **最可能出成果** | **登录态越权**（必须要有账号）> 上传点 > App API 未授权 |

### C · 多租户 SaaS（**杠杆最高**）

| 项 | 内容 |
|---|---|
| **典型资产面** | 客户子域池（`<客户>.平台域名`）、共享入口（`app*.cloud.xxx`）、开放平台/API 网关、多租户后台 |
| **优先攻击面** | ①**跨租户越权**（`id`/`appid`/`siteid`/`tenant` 参数换一个能否读别人）②开放平台签名/鉴权绕过 ③API Key 管理越权 ④共享入口 Host/路径穿越 |
| **P1 数据面** | 一跳影响**全部客户**：客户用户数据、订单、内容；即使只泄露客户清单也值商业情报 |
| **常见坑** | ①纯"租户配置"泄露会被判**危害小**（无 PII、无后台功能）②后台几乎都要登录 ③共享入口常统一 403+固定字节数 |
| **实证** | 某SaaS平台（<客户域名>）：`/site/index?id=N` 未授权遍历 82/120 个租户配置（域名+公众号 appId+微信签名）→ 中危，但**无 PII，加固全部失败**，可能被判同 C-001 命运。<br>某CDN服务商（starchent.com）：0 条，47 个接口全需实名+API Key |
| **最可能出成果** | **能读到别的租户的用户数据/订单**（不是配置）> 后台可操作 > 节点密钥泄露 |

### D · 数据交易 / 数据平台

| 项 | 内容 |
|---|---|
| **典型资产面** | 数据超市、接口市场（几十上百个 API）、API Key 管理、文档 SDK、充值/计费、图床/附件 |
| **优先攻击面** | ①**接口鉴权与配额绕过**（免费接口限量绕过、付费接口未授权）②API Key 越权查看/重置 ③上传点（图床常是弱面）④计费/充值金额篡改 |
| **P1 数据面** | 平台上的数据商品本体（第三方数据）、用户调用记录、Key |
| **常见坑** | ①接口文档页常写「登录后可见接口地址」「调用门槛实名认证」→ **没账号整块不可达** ②这类站常挂敏感 WAF，**攻击特征请求可能直接打挂全站** |
| **实证** | 某CDN服务商：0 条；接口全需实名；**单条 XSS 探测导致全站 502 持续 90+ 分钟**（单 CDN + 源站防火墙拉黑回源）→ 详见 `pentest-full-pipeline` 4.1 |
| **最可能出成果** | 文档/SDK 里的硬编码 key > 未授权接口 > 图床上传 |

### E · 司法 / 政务数据开放平台（**P1 优先级最高**）

| 项 | 内容 |
|---|---|
| **典型资产面** | 开放平台 API 市场、文档与 SDK 下载、控制台/应用管理、数据查询（案件/文书/企业涉诉）、试用申请 |
| **优先攻击面** | ①**数据查询接口未授权/越权**（能否直接查案件、文书、涉诉）②appkey/secret 泄露（前端 JS、示例代码、SDK 包）③签名算法绕过 ④试点/试用账号配额绕过 |
| **P1 数据面** | 裁判文书（含当事人姓名、身份证、住址、案由）、企业涉诉、失信名单 —— **高敏感，绝对不能批量取** |
| **常见坑** | ①首页可能 1MB+，慢，抓取要 timeout ②页面里混着第三方组件版权串（salesforce/pdf.js），别当归属证据 ③这类平台常做严格鉴权，未授权面小 |
| **实证** | 中国某司法数据机构研究院（<客户域名>）：本轮待测（2026-11-12 18:00 开跑） |
| **本类红线** | 只取 1–3 条**脱敏**样本 + 接口自报条数；绝不批量查询/下载/外传；不许注册企业应用 |

### F · 医疗

| 项 | 内容 |
|---|---|
| **典型资产面** | 官网/新闻/科室、**预约挂号、在线问诊、检验检查报告查询、体检系统**、内部 OA、公众号/小程序后端、VPN/远程运维 |
| **优先攻击面** | ①**报告查询 IDOR**（换身份证号/就诊卡号/手机号能否看他人报告）②挂号/问诊接口未授权 ③老系统（HIS/LIS/PACS 前置、随访、体检）版本泄露与 Nday ④边界 VPN |
| **P1 数据面** | 患者姓名、身份证、就诊记录、检验报告、处方、医保信息 —— **最高敏感级别** |
| **常见坑** | 医疗系统大量是**厂商产品**（某医疗 SaaS/某 HIS 厂商）→ 先查平台「不关注名单」，命中就降级并在报告强调"该院自建部署实例（事件型）" |
| **实证** | 某大学附属医院（<客户域名>）：本轮待测（2026-11-12 18:00 开跑） |
| **本类红线** | 绝不影响诊疗业务；不做挂号/支付；患者信息只取 1–3 条脱敏样本 |

### G · 软件外包 / 定制开发

| 项 | 内容 |
|---|---|
| **典型资产面** | 官网/案例展示、产品介绍、**下载中心（源码包/文档/演示）**、留言/联系表单、**后台登录口**、招聘 |
| **优先攻击面** | ①**下载中心的备份/源码/数据库文件**（这类公司最常犯）②后台未授权/弱口令（默认口令优先，受控小字典次之）③留言/联系接口的注入与未授权读 ④Git/SVN/Jenkins 等开发设施暴露 |
| **P1 数据面** | 客户项目数据、测试库、合同与报价单 |
| **常见坑** | ①客户案例站群（同 IP 旁站）**不是本靶标**，只作线索 ②这类公司安全投入低但也常只有静态站 ③**高价值入口常是不起眼的非标端口**（如 8888 宝塔面板），且**对 curl 默认 UA 隐藏**，必须用浏览器 UA 复测（见通用规律 #10） |
| **实证** | 天津睿晨（lldong.com）：2026-11-12 实测完成，**0 条可提交**。<br>资产面极小：<IP> 仅开 80/443/8888；80/443 是纯静态单页（leadForm 是模板占位、/api/lead 404）；**8888 = 宝塔面板登录页（公网可达、未启安全入口、http 明文、无 IP 白名单）= 唯一高价值入口**，但禁止试口令。<br>教训：面板对 curl 默认 UA 隐藏（404/146B），换浏览器 UA 才 200/30,587B |
| **最可能出成果** | 下载中心泄露 > 后台未授权 > 开发设施（Git/Jenkins） |

### H · AI / 数字化解决方案商

| 项 | 内容 |
|---|---|
| **典型资产面** | Next.js/SPA 官网、**AI 能力接口与模型调用**、试用申请、控制台、文档与 SDK、招聘 |
| **优先攻击面** | ①**AI 接口未授权调用**（能白嫖=实打实损失，可量化）②appkey/模型 key 泄露（前端 JS、`/_next/static/chunks/*`）③试用申请接口注入/未授权读 ④控制台越权 |
| **P1 数据面** | 客户对话/知识库内容、模型 key、租户数据 |
| **常见坑** | ①Next.js RSC 站，HTML 里大量 unicode 转义，**不还原因看不到内容**（解码后才见页脚/文案）②公司名可能只在「关于我们」③**归属常只靠 ICP 号，需另行核对主体** |
| **实证** | 杭州诗路云（lingdayun.cn）：原本待测，**2026-11-12 被用户替换为某机器人公司创新（<客户域名>）**，未实际测试。<br>教训：该站页脚只有 `浙ICP备2025184006号` 而无公司名 → 归属需靠 ICP 查询坐实，这类站优先级应降低 |
| **最可能出成果** | AI 接口未授权（可量化损失）> key 泄露 > 试用接口 |

### I · 机器人 / 具身智能（硬件 + 开发者生态）

| 项 | 内容 |
|---|---|
| **典型资产面** | 官网/产品页、**开发者平台与 SDK/固件下载**、设备管理云平台、API/开放平台、招聘、渠道/客户门户、GitHub 组织 |
| **优先攻击面** | ①**SDK/固件/示例代码里的硬编码 key、内网地址、默认口令**（下载接口常有未授权/路径穿越）②设备管理/OTA 接口未授权与越权 ③API 未授权调用 ④招聘系统 PII ⑤公开仓库泄露 |
| **P1 数据面** | 设备身份与固件、客户/订单、员工与简历、生产参数 |
| **常见坑** | ①官网在 CDN 后（8 个 IP），**别把回源打挂** ②页脚常是英文 Copyright 串，截图要能看清全名 ③**绝不能向真实设备下发指令/固件**（物理安全）④行业归属在「制造业 / 科学研究和技术服务业」之间，要按工商范围定 |
| **实证** | 某机器人公司创新（上海，<客户域名>）：2026-11-12 无账号轮 0 条可提交；**2026-11-13 用自注册账号深挖其商城 store.<客户域名> 拿到 2 条**：<br>① `GET /api/order_config` **未授权**（无 token 与有 token 响应 md5 相同）→ 对公账户+员工邮箱+内部地址；<br>② `GET /api/order/sales_info` **越权**（任意注册用户含 level=0 新号）→ 5 名销售实名+手机+邮箱，参数 page/limit/id/uid 全无效恒返回全量。<br>**同类已验证不可越权**：`/api/user`、`/api/order/list`、`/api/address/list` 的 uid 参数被忽略；`/adminapi/*` 用普通 token 正确拒绝；`/api/private-file/{id}` 403。 |
| **最可能出成果** | SDK/固件里的 key 与默认口令 > 设备管理接口未授权 > 下载路径穿越 |

## 二点五、通用接口挖掘手法 M1–M9（源自公开实战复盘）

> **为什么单列**：9 个靶标里 5 个死于「找不到接口」或「判不了鉴权」。这九条专治这两个问题。
> **来源**：`/share/2521`（数据泄露实战，含高校案例）、`/share/4420`（0→1 挖出 573 万用户）、`/share/4664`（签名逆向）。

### ⭐M7 · 响应过度（Over-fetching）—— 高校/教育场景**命中率最高**

| 项 | 内容 |
|---|---|
| **触发条件** | 任何「下拉框 / 选择器 / 模糊搜索」接口：选指导老师、选班级、选课程、选部门、搜索用户 |
| **动作** | 抓该搜索接口响应，**逐字段比对前端实际展示的字段**，看后端多返回了什么 |
| **判据** | 响应含前端未展示、且属个人信息或业务的字段（手机/身份证/学号/工号/学院/家庭地址） |
| **证据** | 前端界面截图（只显示 N 个字段）+ 原始响应（多出字段）**同屏对照** |
| **原文案例** | 「边缘功能处，选择指导老师，模糊搜索可出现姓名、学号、学院，但后端数据返回了大量敏感信息」 |

### ⭐M1 · JS 碎片关键词全局搜索

| 项 | 内容 |
|---|---|
| **触发条件** | 登录后前端功能极少 / 只有 1–2 个请求 / 目录爆破无果 / api 文档 403 |
| **动作** | F12 → 全局搜索（Ctrl+Shift+F）**已抓到接口名的碎片**：`api/`、`user`、`stu`、`jwc`、`lib`、`tenant`、`menu`，**不要搜完整接口名**；命中的路径正则提取后丢 Burp 批量跑 |
| **判据** | 搜出前端页面未出现的接口路径，且请求返回非 404 |
| **失败判据** | 全部 401/403 且无 bypass → 转 M2 |
| **原文实证** | 前端空白、仅 2 个请求 → JS 挖出接口 → 最终 573 万用户昵称+手机号 |

### ⭐M2 · 接口参数串联

| 项 | 内容 |
|---|---|
| **触发条件** | 某接口返回了像"标识"的值：`tenantId`/`siteId`/`orgId`/`deptId`/`sign`/`appKey` |
| **动作** | 把该值带到其它接口对应参数位；再试改一位/置空/换已知值 |
| **判据** | 携带后返回 200 且含业务数据（不是错误提示） |
| **原文实证** | 接口 A 返回 `tenantId` → 调接口 B → 573 万用户；另一例接口 A 可遍历 `sign` → 用 sign 在接口 B 拿敏感信息 |

### M3 · 请求方法补测

| 项 | 内容 |
|---|---|
| **触发条件** | 接口 200 但内容是"请求方式错误/方法不允许/参数缺失" |
| **动作** | 同路径依次试 GET / POST / PUT / DELETE（带合理 body） |
| **判据** | 换方法后返回业务数据 |

### M4 · API 与 Web 分端口

| 项 | 内容 |
|---|---|
| **触发条件** | 主站是静态页/SPA，但同 IP 还有别的端口开着 |
| **动作** | httpx 端口从 80/443 扩到 8080/8081/8070/8071/9000/9090/7001/8443；**同 IP 不同端口当独立站点测** |
| **原文实证** | 「api 站点（8070）和网站地址（8071）不一样」——只看 80/443 会漏 |

### M5 · Webpack 原码里的「接口清单接口」

| 项 | 内容 |
|---|---|
| **触发条件** | 站点有 webpack/vite 产物（`/static/js/app.*.js`、`/assets/index-*.js`） |
| **动作** | 拉主包搜 `api`/`swagger`/`openapi`/`api-docs`/`lyapi`；命中 json 类资源时**不要只试根目录**，按 JS 拼出的真实路径请求 |
| **判据** | 返回接口清单（数组/JSON） |
| **注意** | 原文提示：根目录直接访问 `lyapi.json` **无任何返回** |

### M6 · GraphQL 内省查询

| 项 | 内容 |
|---|---|
| **触发条件** | 指纹或 JS 里出现 `graphql`/`gql`/`apollo` |
| **动作** | 用字典 `runs/tools/paths_graphql.txt`（21 条）探测；命中后发 `{"query":"{__schema{types{name fields{name}}}}"}` |
| **判据** | 内省返回 schema → 全部接口可枚举 |
| **原文实证** | GraphQL 内省导致全部接口泄露 → 调试出未授权访问 + 任意用户登录 |

### M8 · 参数遍历

| 项 | 内容 |
|---|---|
| **触发条件** | 参数是自增 id / 顺序号 / 可预测值 |
| **动作** | 改 id 前后各试 3–5 个值，比对返回是否变成他人数据（只取条数 + 1–2 条脱敏样本） |
| **判据** | 返回**非当前账号**拥有的数据 |
| **红线** | 只证明"能读到"，**不批量导出** |

### M9 · 小程序/Web 签名参数逆向

| 项 | 内容 |
|---|---|
| **触发条件** | 改参数后连环报错：「ts 有问题」→ 改 ts 报「nonce」→ 改 nonce 报「mac」 |
| **动作** | 判定为签名型鉴权 → 反编译小程序 / F12 全局搜 `mac`、`sign`、`signature` → 找算法 → 本地复算 |
| **判据** | 自算签名与官方一致 → 改 personalId 等参数仍返回他人数据 |
| **注意** | 原文还有「源码里默认密码 111111 + 无验证码」→ 属**弱口令**：受控尝试（控速、防锁定），命中即取证 |

### 用法次序（资源有限时）

```
先 M7（下拉框响应过度）→ 再 M1（JS 挖接口）→ 再 M2（参数串联）
→ 再 M4（换端口）/ M3（换方法）→ 最后 M5/M6/M8/M9
```

## 三、跨类型通用规律（9 个靶标实测）

| # | 规律 | 实证 |
|---|---|---|
| 1 | **登录态是拿大漏洞的硬瓶颈**。9 个靶标里 4 个（化龙、某CDN服务商、中教互联、诗路云待验）的核心面全在登录后，而**注册普遍要短信验证码、经常发不出** | 化龙、jiaoyu 都卡在这 |
| 2 | **未授权 200 ≠ 泄露**。受保护资源爱返回「空壳 + JS 跳登录」 | Domino 706B 误报（C-003） |
| 3 | **纯配置/标识类泄露会被判危害小**，即使类型完全对口 | 选课配置页被驳（C-001） |
| 4 | **多租户平台杠杆最高**，但必须打在「用户数据」而不是「租户配置」上 | 某SaaS平台实测 |
| 5 | **WAF 形态决定打法**：全站 410（化龙）→ 换未防护子域；UA 拦截（jiaoyu）→ 带浏览器 UA；JS 挑战（acw_sc__v2）→ 用真实浏览器 | 三个靶标三种 WAF |
| 6 | **单 CDN 节点 + 源站防火墙 = 高危宕机风险**，一条攻击特征请求就能打挂全站 | 某CDN服务商两次 502 |
| 7 | **PII 集中在**：招聘简历、论坛用户、数据平台、医疗报告、司法文书 | 按类型直接定位 |
| 8 | **系统可能是厂商产品**（同一套代码多单位部署）→ 先判断是否厂商产品再决定投入面；平台是否收录属平台层规则，不在本技能 | 医疗/教育最常见 |
| 9 | **归属证据优先级**：ICP 主体 > 页面自身标识（页脚/标题含单位名）> 官网页脚版权 > 媒体报道 | 9 个靶标都验证过 |
| **10** | **目录/面板/接口发现必须跑两轮 UA**：curl 默认 UA + 浏览器 UA。实测 `lldong.com:8888` 对默认 UA 恒返回 nginx 404/146B（82 条面板字典全落空），**换浏览器 UA 后 `/login` 立刻 200 / 30,587B=宝塔面板**。只跑一轮 UA 会把存在的面板/后台误判为不存在 | 天津睿晨（2026-11-12） |
| **11** | **面板类资源常需 Referer + 会话 Cookie**：如宝塔的 `/static/js/*.js` 直接 GET 返回 404，**不能据此判定资源不存在**；要带 Referer 与已获得的 Cookie 再试 | 天津睿晨 |
| **12** | **自注册账号就能打的越权要优先试**：不少业务站对"任意登录用户"返回**全量**业务数据（如员工通讯录、销售对接人、对公账户配置），不需要第二个账号也不需要特权。判据：换 `page/limit/id/uid` 参数后返回是否**恒为全量**——恒为全量 = 超范围读取。<br>另：登录后先摸清**鉴权头形态**（某机器人公司商城是 `Authorization: Bearer <localStorage JWT>`，不是 Cookie），否则所有复现都会 401 | 某机器人公司商城（2026-11-13）

## 四、按「最快出成果」排序（资源有限时怎么选）

```
1. 有登录态 → 直接冲越权/IDOR（C/F/E 类价值最高）
2. 无登录态但有多租户 → 冲跨租户数据（不是配置）
3. 无登录态 + 单租户 → 冲未授权接口里的 PII + 上传点
4. 都没有 → 下载中心/开发设施（G 类常出低垂果实）
5. 还都没有 → 老实收口，输出「缺什么才能继续」
```

## 五、维护协议（每测完一个靶标就补）

1. 找到对应类型节，把「实证」里补上：**靶标名 + 实际产出 + 卡在哪**。
2. 若发现该类型有**新的高频攻击面**，加进「优先攻击面」。
3. 若发现某类**固定踩同一个坑**，加进「常见坑」并考虑写进 `pentest-full-pipeline`。
4. 出现**第九种类型**时，新增一节（I、J…），并把它加进第一节的识别表。
5. 第三节「通用规律」只收**跨类型**成立的结论；只适用于单类型的放回该类。
