## 提示词原文（照录）

> 「我想实现 [具体结果]。从预期的结果开始，然后反向工作。精确地确定实现这一目标所需的步骤、技能、工具、决策和里程碑。向我解释最有效的路径。」

## 本质

不问「我现在能做什么」，只问「终点长什么样，往回退第一步是什么」。**必须先把终点写成可验收的状态**，否则整条链都是假的。

## 执行规程

1. **先钉终点**：把 `[具体结果]` 改写成一句可验收的话（有主体、有数量、有判定方式）。改不了就问，别带着模糊终点倒推。
2. **倒推成 5–9 个里程碑**，从终点往回写。每个里程碑写三样：
   - 完成标志（怎么知道到了）
   - 前置条件（必须已经有什么）
   - 卡点（这一步最容易死在哪）
3. **每步标注资源**：需要的**技能**（人会/会学）、**工具**（现成/要买/要建）、**决策**（这一步必须选一个什么）。
4. **标出关键路径**：哪一步拖了整条链就废（通常 1–2 个），明确写「这一步是唯一不能省的」。
5. **给「最有效路径 vs 稳妥路径」两条**，并说清取舍：最有效路径通常砍掉了哪些看似必要其实可跳的步骤。
6. **最后回到现在**：写「你今天/本周就能做的第一个动作」，必须是半天内能完成的具体动作。

## 输出骨架

```
终点（可验收）：…

倒推里程碑
M5 ← 完成标志 / 前置 / 卡点
M4 ← …
…
M1 ← …

关键路径：M2、M4（理由）
资源清单：技能… ｜ 工具… ｜ 必须做的决策…

最有效路径：跳过 ___，先做 ___
稳妥路径：…

现在就能做的第一个动作：…
```

## 禁止

- 正着写（「第一步先调研，第二步…」）——那不是倒推。
- 里程碑含糊（「搭建基础」「完成准备」）。
- 只给路径不给卡点（等于给了张会塌的桥）。
- 终点写成愿望（「成为专家」「做起来」）。

## 做成了的判据

读完能立刻指出「我卡在 M2」，并且知道 M2 的完成标志是什么。
