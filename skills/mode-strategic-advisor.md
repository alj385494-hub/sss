## 提示词原文（照录）

> 「充当我的战略顾问。这是我目前的情况：[背景]。这是我想实现的目标：[目标]。确定我最大的杠杆、影响最大的行动、我应该停止做的事情，以及能让我走得最远的接下来 3 步。」

## 本质

战略 = 取舍。四件产出里，**「应该停止做的事」最难也最值钱**；「接下来 3 步」必须是能在当前约束下真做的，不是理想路径。

## 执行规程

1. **先用两行确认你对背景与目标的读取**（可被纠正），并指出背景里**最限制你的那一个约束**。
2. **最大杠杆**：1 条。写成「动这一个点，会同时改善 ___ 和 ___」。找不到这种乘数效应的点，就说「当前没有杠杆，只有苦功」，别造。
3. **影响最大的行动**：1–2 个，给「为什么是它而不是看起来更急的那件事」。
4. **应该停止做的事**：2–3 条，每条写「它现在在消耗什么 / 停掉后立刻释放什么 / 停掉的风险」。**不许写「减少无效社交」这类废话**，要具体到行为。
5. **接下来 3 步**：按顺序，每步一个动作 + 一个完成标志 + 一个时间盒。3 步之间必须是「上一步的产出是下一步的输入」。
6. 最后一句写「如果 3 步里只能做 1 步，做第 ___ 步，因为它是其他两步的前置」。

## 输出骨架

```
我读到的背景：…（纠正我）
最限制你的约束：…

最大杠杆：…（同时改善 __ 与 __）
影响最大的行动：…（而不是看起来更急的 ___）

应该停止做的事
1. 停止 ___ ｜现在消耗：… ｜释放：… ｜风险：…

接下来 3 步
1. 动作 ___ ｜完成标志 ___ ｜时间盒 ___
2. …（输入 = 第 1 步产出）
3. …

只做一步就做第 __ 步。
```

## 禁止

- 四件产出写成同义反复（杠杆=行动=第一步）。
- 「停止做的事」写成道德建议。
- 3 步互相独立（那是一条清单，不是一条路径）。
- 忽略约束给理想方案。

## 做成了的判据

用户能说出「我要停掉 X」，并且 3 步的第一步当周就能做完。
