# CORS 与 CSRF 的取舍判定

> 先说结论：**这两类在多数平台是忽略项或低危**。
> 本技能的重点不是"怎么利用"，而是**判断什么时候根本不值得投入**。

## 一、CORS：什么情况才算

### 三档判断

| 配置 | 能否读数据 | 结论 |
|---|---|---|
| `ACAO: *` 且无 `Allow-Credentials` | ❌ 不能带 Cookie | **不算**（最常见，扫描器最爱报） |
| `ACAO: *` + `Allow-Credentials: true` | ⚠️ 浏览器会拒绝（规范禁止组合） | 不算 |
| `ACAO: <攻击者域>` + `Allow-Credentials: true` | ✅ **可跨域读带凭据的响应** | ✅ 才算 |

### 验证步骤

```bash
# 1. 带 Origin 请求，看是否回显
curl -sI "https://target/api/user" -H "Origin: https://evil.example.com" | grep -i "access-control"

# 2. 若回显 + Allow-Credentials: true，再用真实浏览器带 Cookie 验证能否读到数据
```

**必须证明的**：用攻击者域的页面，**真的读到了受害者的业务数据**（截图 + 浏览器控制台输出）。

### 什么情况值得交

- 可跨域读到**含 PII 的接口**（用户信息、订单、通讯录）
- 可跨域调用**能改状态的接口**

**只有 `ACAO:*` 一律不交。**

## 二、CSRF：什么情况才算

### 分档

| 场景 | 价值 |
|---|---|
| 普通表单无 token，但改的是**非敏感信息**（如昵称） | ❌ 低 |
| 改**密码/邮箱/手机号/支付设置**且无 token | ✅ 高 |
| 无 token 且**无 SameSite**，可自动提交 | ✅ 才算完整 |
| 有 `SameSite=Lax/Strict` | ❌ 多数场景不可利用 |

### 验证要点

1. 目标请求**无 CSRF token** 或 token 不校验
2. **无 `SameSite` 限制**（或 `SameSite=None; Secure`）
3. 构造一个自动提交的 HTML 页面，在**真实浏览器**里打开，确认状态真的被改
4. 改完**立即改回来**并记录

## 三、判定标准

| 结果 | 结论 |
|---|---|
| CORS 回显 + 可读 PII | ✅ 中（需浏览器实证） |
| CSRF 可改密码/绑定项 | ✅ 中高 |
| 只有 `ACAO: *` | ❌ 不算 |
| 有 token 或 SameSite | ❌ 不算 |
| 需要用户手动粘贴代码 | ❌ 不算 |

## 四、证据要求

1. CORS：带 Origin 的响应头 + 浏览器里读到数据的截图
2. CSRF：无 token 的请求 + 自动提交页面 + 状态被改的证据 + 复原记录
3. **必须说明为什么这算**（不是"配置有问题"，而是"能读到什么/改到什么"）

## 五、失败判据（什么时候直接放弃）

- CORS 只有 `*` 无 credentials → 放弃
- CSRF 目标有 token 或有 SameSite → 放弃
- 只能改无关紧要的字段 → 放弃
- 需要受害者主动配合（粘贴/点击两次）→ 放弃

## 六、边界

- CSRF 验证只改**自己的测试账号**的设置，改完复原
- 不用 CORS 批量读他人数据（读 1 条证明即可）
- 不构造蠕虫式自动提交

## 七、为什么单列一个技能

因为这两类**最容易被扫描器误报**，也最容易被"看起来像漏洞"骗走时间。
本技能的作用是：**在花时间做证据之前，先判断值不值得**。

## ⚠️ 判据修正（2026-11-15，HackerOne 实证）

**"CSRF 多数被忽略"这句话说得太绝对。** HackerOne 公开披露出真实收录案例：
Revive Adserver「CSRF in tracker invocation page」→ **Medium / Resolved**。

分界线在这里：

| 情形 | 判定 |
|---|---|
| 只改**无害状态**（改昵称、改头像、加收藏）、或需要用户再确认一步 | 忽略 |
| **能改关键状态**：投放规则、计费配置、收款账号、密码、邮箱、审批结论、权限归属 | **Medium 起**，值得交 |
| 受害者是**已登录的管理员**且后果可扩散（改配置影响下游、加子账号） | 可到 High |

判定问句：**"受害者点一下，他自己会失去什么/多出什么？"**
答得出具体变化（钱、权限、数据）→ 算；答不出 → 忽略。
