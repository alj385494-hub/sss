## 提示词原文（照录）

> 「我将给你 [一篇文章、一本书、一份记录或一份文件]。不要只是总结它。提取最有价值的见解、隐含的假设、实际应用、反直觉的教训以及我可以立即应用的想法。」

## 本质

摘要压缩信息，提取**改变判断**。五类产出固定，缺一类就等于只做了摘要。

## 执行规程

1. **先给「这材料在回答什么问题」**（一句），再给「它其实没回答什么」（一句）。这两句定住了它的位置。
2. **五段固定产出**：
   - **最有价值的见解**（3–5 条）：必须是「知道了会改变做法」的，附原文定位（章节/段落/行号）
   - **隐含假设**：作者没说但必须成立的前提，标 `成立 / 存疑 / 明显不成立`
   - **实际应用**：把它用在我的具体场景上，写成「如果我要做 X，按这条我会改 ___」
   - **反直觉的教训**：与常识相反且作者给了支撑的那条（没有就明说没有）
   - **可立即应用的想法**：1–3 个，每个 ≤1 天可验证
3. **可信度标注**：对关键结论标 `作者实证 / 作者推断 / 转述他人 / 无法核实`。**这一步不许省**，否则提取物会被当成事实传下去。
4. **不评价文笔与立场**，只处理信息。
5. 材料里有矛盾处单列一条「材料内部的不一致」。

## 输出骨架

```
它在回答：… ｜ 它没回答：…

最有价值的见解
1. …（定位：第 X 节/第 N 段）｜可信度：作者实证/推断/转述

隐含假设
- …（成立/存疑/不成立）

实际应用（落到你的场景）
- 若你要…，按这条改…

反直觉的教训
- …（或无）

可立即应用（≤1 天可验证）
1. …

材料内部不一致
- …
```

## 禁止

- 写成章节摘要或「本文介绍了…」。
- 引用不给定位（无法回查=不可信）。
- 把作者的推断当结论输出。
- 五段只写三段就说「其余不适用」（不适用要写理由）。

## 做成了的判据

用户能指出至少一条「我原来不是这么想的」。
